# Benchmark analysis of the pyflate benchmark

## Purpose of the benchmark:
Measures how fast Python can decompress a file in .bz2 compressed format. It is written entirely in pure Python, with no calls to fast C libraries.

## Data Structures and Algorithms used

bzip2 is a 5 stage compression algorithm:

1. Run-Length Encoding - pass #1: Replace sequence of 4-255 identical consecutive bytes with a single character and count. Prevents repetative data from degrading the BWT sorting phase.

2. Burrows-Wheeler Transform (BWT): Reorders chunks of the file to group similar characters together. Talk about this in presentation. Explain the algorithm, and give the PEPPER$ example: https://www.baeldung.com/cs/bwt-string-algorithm . Show both encoding and decoding

3. Move-to-Front (MTF) Encoding: turns identical characters to 0's, which keeps logical meaning of repeated character, but helps Huffman Coding.

4. Run-Length Encoding (RLE, Pass 2): targets the large amount of 0's generated by the last stage.

5. Huffman Coding: encodes characters by their frequency. High frequency characters receive low bitcount sequences. Give example.
